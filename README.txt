VEIL iPhone Web App Preview

This is a mobile-friendly web-app prototype, not a complete online multiplayer game.
It can be hosted over HTTPS and then added to an iPhone Home Screen from Safari.

To install on iPhone after hosting:
1. Open the hosted HTTPS address in Safari.
2. Tap Share.
3. Choose Add to Home Screen.
4. Tap Add.

Online multiplayer, real invitations, server-side game state, reconnection behavior, complete pot logic, and final rule verification are not implemented in this preview. It uses sample local opponents and should not be represented as the finished game.
